Ограничения и безопасность:
- Комплект прошёл локальную структурную проверку, но ещё не тестировался на вашем реальном GitHub Pages/Firebase.
- Ничего не загружено в GitHub и ничего не изменено в Firebase.
- Не публикуйте firestore.rules без отдельного согласования.
- Для директора users/{UID} должен содержать role="school_director" и schoolId, совпадающий с ID документа schools/{schoolId}.
- При одобрении заявки создаётся schools/{ID_заявки}. Если у существующей школы другой ID, сначала нужно сверить документы; не меняйте schoolId наугад.
- Реализованы базовые регистрация, вход, админ-панель и просмотр школы директором. Полные модули учителей, учеников, оценок, расписания, посещаемости и библиотеки ещё впереди.
- Переключатель языка переводит основные сообщения; некоторые системные сообщения Firebase могут быть на английском.

Установка: сохраните резервную копию, затем загрузите файлы из архива в корень репозитория GitHub Pages. После загрузки отдельно проверьте вход администратора и директора. Правила Firestore меняйте только после отдельного разрешения.
