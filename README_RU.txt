SCHOOL ALLIANCE — СТАРТОВЫЙ ПРОЕКТ

Что это:
- Начальный мобильный веб-прототип School Alliance.
- Работает в браузере телефона.
- Есть русский/таджикский переключатель.
- Есть форма заявки школы и демонстрационная панель подтверждения.
- Заявки сохраняются только в локальном браузере этого устройства.

ВАЖНО:
Это НЕ готовая многопользовательская система и НЕ APK.
Пока нет настоящего сервера, авторизации, защиты ролей и общей базы данных.
Не используйте реальные персональные данные детей.

КАК ПОСМОТРЕТЬ НА ТЕЛЕФОНЕ:
1. Распакуйте ZIP в приложении «Файлы».
2. Откройте index.html в браузере или HTML-просмотрщике.
3. Чтобы получить устанавливаемый ярлык/PWA, файлы нужно разместить на HTTPS-хостинге.
4. Для настоящей работы нескольких школ нужно подключить серверную базу данных и авторизацию.

СЛЕДУЮЩИЕ ЭТАПЫ:
1. Создать проект Firebase.
2. Настроить Firebase Authentication для аккаунтов.
3. Создать Cloud Firestore с правилами безопасности по schoolId и ролям.
4. Добавить подтверждение школ только главным администратором.
5. Добавить кабинеты директора, учителя, ученика и родителя.
6. Проверить безопасность данных и только потом запускать пилот в школе.

Рекомендуемый пилот:
Сначала использовать тестовые данные Школы №15, Пянджский район.
Перед реальным запуском получить разрешение руководства школы и согласовать обработку персональных данных.


ОБНОВЛЕНИЕ: ПОДКЛЮЧЕНИЕ FIREBASE AUTHENTICATION
- Добавлена вкладка «Вход» с Firebase Email/Password для проекта School-Alliance.
- Это пока только проверка входа. Роли, профили пользователей в Firestore и разграничение доступа НЕ реализованы.
- Для работы Firebase JavaScript-модулей откройте сайт через HTTPS-хостинг или веб-сервер. Открытие index.html напрямую как file:// может не работать.
- Перед размещением добавьте домен сайта в Firebase Console > Authentication > Settings > Authorized domains.
- В Firestore оставьте закрытые правила: allow read, write: if false; пока не будут подготовлены и проверены безопасные правила.
- Не вводите настоящие данные детей до завершения настройки ролей и правил доступа.
- Конфигурация Firebase для веб-приложения включена в index.html. Не публикуйте пароли или закрытые ключи сервисных аккаунтов.
